# Premium Health UI V2

Mục tiêu: tiếp tục đưa Health_Care gần với visual mockup đã duyệt nhưng không thay đổi business logic, dữ liệu sức khỏe, Secure Vault, Profile Privacy hoặc Control Plane.

## V2
- hero minh họa vector nội bộ, không phụ thuộc ảnh ngoài hoặc network;
- profile strip nổi với avatar chữ cái, tuổi và selected state;
- glass cards, spacing và shadow tinh chỉnh;
- quick actions, checklist, weekly strip và form controls có hover/pressed/focus rõ hơn;
- responsive 1180 / 880 / 620 px;
- reduced-motion;
- không có fetch/API/Control Plane dependency trong các component UI mới.

## Ranh giới
UI V2 không thay đổi Device Gate, WHO growth, reminder permission, Vault encryption, Privacy policy hay đường dữ liệu Admin.
